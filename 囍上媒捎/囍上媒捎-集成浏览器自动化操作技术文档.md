# 囍上媒捎 - 集成浏览器自动化操作技术文档

> 文档版本: 1.0
> 编写日期: 2026-07-29
> 适用场景: 通过TRAE集成浏览器工具自动化操作H5版App

---

## 一、概述

### 1.1 使用的工具

在本次喜上媒捎项目中，自动化操作App使用的是 **TRAE IDE 内置的集成浏览器工具（Integrated Browser MCP）**，而**不是** AutoJS。

#### 与AutoJS的区别

| 对比项 | TRAE集成浏览器 | AutoJS |
|--------|---------------|--------|
| 运行平台 | PC端浏览器 | Android手机端 |
| 操作方式 | 通过MCP协议控制浏览器 | 通过Android无障碍服务 |
| 适用场景 | H5网页版App | 原生Android App |
| 脚本语言 | JavaScript（浏览器内执行） | JavaScript（手机端执行） |
| 需要Root | 不需要 | 部分功能需要 |
| 网络环境 | PC端网络 | 手机网络 |

### 1.2 工具简介

TRAE集成浏览器是基于MCP（Model Context Protocol）协议的浏览器自动化工具，内置于TRAE IDE中。它提供了一套完整的浏览器操作API，包括页面导航、元素点击、文本输入、截图、JavaScript执行等功能，可以实现对任意网页的自动化操作。

在本次项目中，我们通过该工具访问了喜上媒捎的H5版本（`https://h-app.xsms-club.com/`），模拟真实用户操作完成了登录、会员查询、消息发送等任务。

## 二、安装过程

- 已安装 TRAE IDE（版本 >= 1.0）

- 拥有喜上媒捎App的账号


如果浏览器成功打开页面并返回截图，说明工具已正常工作。

## 三、操作步骤

### 3.1 整体操作流程

```
┌─────────────────────────────────────────────┐
│           集成浏览器自动化操作流程            │
├─────────────────────────────────────────────┤
│                                             │
│   1. 打开H5版App页面                         │
│        ↓                                    │
│   2. 获取页面快照 (browser_snapshot)          │
│        ↓                                    │
│   3. 识别页面元素和引用ID (ref)               │
│        ↓                                    │
│   4. 执行操作 (点击/输入/滚动)                │
│        ↓                                    │
│   5. 等待页面响应 (browser_wait_for)          │
│        ↓                                    │
│   6. 再次获取快照确认操作结果                 │
│        ↓                                    │
│   7. 重复步骤3-6直到任务完成                  │
│                                             │
└─────────────────────────────────────────────┘
```

### 3.2 详细操作步骤

#### 步骤1: 导航到App页面

使用 `browser_navigate` 工具打开喜上媒捎H5版：

```
工具: browser_navigate
参数:
  url: "https://h-app.xsms-club.com/"
```

#### 步骤2: 获取页面快照

使用 `browser_snapshot` 获取页面的无障碍树（Accessibility Tree），这是一个比截图更好的方式，因为它可以提供页面元素的结构化信息：

```
工具: browser_snapshot
参数: (无参数，获取当前页面完整快照)
```

快照返回示例：
```yaml
- role: StaticText
  name: 密码登录
  ref: e545
- role: spinbutton          # 手机号输入框
  ref: e547
- role: textbox             # 密码输入框
  ref: e549
- role: StaticText
  name: 登录
  ref: e551                  # 登录按钮
```

> **关键概念：`ref` 是元素的唯一引用ID**，后续所有操作（点击、输入等）都需要使用这个ref来定位元素。

#### 步骤3: 登录App

**3a. 输入手机号：**
```
工具: browser_type
参数:
  element: "手机号输入框"
  ref: "e547"
  text: "150****0897"
  clear: true
```

**3b. 输入密码：**
```
工具: browser_type
参数:
  element: "密码输入框"
  ref: "e549"
  text: "123456"
  clear: true
```

**3c. 勾选用户协议：**

uni-app框架使用自定义元素，需要通过JavaScript点击：
```
工具: browser_evaluate
参数:
  script: |
    var radio = document.querySelector('.footer .radio');
    if (radio) { radio.click(); return 'clicked radio'; }
    return 'not found';
```

**3d. 点击登录按钮：**
```
工具: browser_click
参数:
  element: "登录按钮"
  ref: "e551"
```

#### 步骤4: 等待登录完成

```
工具: browser_wait_for
参数:
  time: 3    # 等待3秒
```

或等待特定文本出现：
```
工具: browser_wait_for
参数:
  text: "推荐"     # 等待首页加载完成
  timeout: 10000   # 最大等待10秒
```

#### 步骤5: 导航到会员个人主页

通过JavaScript调用uni-app的路由API：
```
工具: browser_evaluate
参数:
  script: |
    uni.navigateTo({
      url: '/pages/recommend/personalHomePage?id=102406119'
    });
    return 'navigating...';
```

#### 步骤6: 打开聊天页面

通过eventChannel传递会员信息并打开聊天室：
```
工具: browser_evaluate
参数:
  script: |
    uni.navigateTo({
      url: '/pages/tabbar/messages/chatroom',
      success: function(res) {
        res.eventChannel.emit('acceptDataFromOpenerPage', {
          isOk: true,
          id: 102406119,
          phone: '13535393410',
          nickname: '小徐一马当先',
          image: 'http://oss-img.xsms-club.com/...'
        });
      }
    });
    return 'navigating to chatroom...';
```

#### 步骤7: 输入并发送消息

**7a. 获取新页面快照：**
```
工具: browser_snapshot
```

**7b. 在输入框中输入消息：**
```
工具: browser_type
参数:
  element: "聊天输入框"
  ref: "e856"       # 从快照中获取的输入框ref
  text: "我可能盐吃多了，总是闲得想你。"
```

**7c. 点击发送按钮：**
```
工具: browser_click
参数:
  element: "发送按钮"
  ref: "e864"       # 从快照中获取的发送按钮ref
```

#### 步骤8: 验证消息发送

发送后获取快照，确认消息出现在聊天界面中：
```
工具: browser_snapshot
```

快照中应显示：
```yaml
- role: StaticText
  name: "12:23"                    # 消息时间戳
  ref: e869
- role: StaticText
  name: "我可能盐吃多了，总是闲得想你。"   # 发送的消息内容
  ref: e870
```

### 3.3 批量发送消息

对于批量操作（如发送15条消息给15个会员），可以使用JavaScript在浏览器内执行异步循环：

```javascript
// 在浏览器中执行的批量发送脚本
var members = [
  {n: '无声飞雪', p: '18926688238', id: 102405578, msg: '智者不入爱河，遇你难做智者。'},
  {n: '勒流刘生', p: '13702268561', id: 101037346, msg: '风都知道我想你，不然怎么总往你方向吹。'},
  // ... 更多会员
];

window.__b2 = [];        // 结果存储
window.__b2d = false;    // 完成标志

function sleep(ms) {
  return new Promise(function(r) { setTimeout(r, ms); });
}

async function run() {
  for (var i = 0; i < members.length; i++) {
    var m = members[i];
    
    // 1. 导航到聊天页面
    await new Promise(function(resolve) {
      uni.navigateTo({
        url: '/pages/tabbar/messages/chatroom',
        success: function(res) {
          res.eventChannel.emit('acceptDataFromOpenerPage', {
            isOk: true, id: m.id, phone: m.p, nickname: m.n
          });
          resolve(true);
        },
        fail: function(e) { resolve(false); }
      });
    });
    
    // 2. 等待聊天页面加载
    await sleep(3000);
    
    // 3. 找到输入框并输入消息
    var ta = document.querySelector('uni-textarea textarea') || document.querySelector('textarea');
    if (!ta) {
      window.__b2.push({n: m.n, p: m.p, s: 'no_textarea'});
      uni.navigateBack();
      await sleep(2000);
      continue;
    }
    
    // 使用原生setter设置值（兼容Vue双向绑定）
    var nativeSetter = Object.getOwnPropertyDescriptor(
      window.HTMLTextAreaElement.prototype, 'value'
    ).set;
    nativeSetter.call(ta, m.msg);
    ta.dispatchEvent(new Event('input', {bubbles: true}));
    ta.dispatchEvent(new Event('change', {bubbles: true}));
    
    await sleep(800);
    
    // 4. 找到并点击发送按钮
    var sendBtn = null;
    var texts = document.querySelectorAll('uni-text');
    for (var j = 0; j < texts.length; j++) {
      if (texts[j].innerText && texts[j].innerText.trim() === '发送') {
        sendBtn = texts[j];
        break;
      }
    }
    
    if (sendBtn) {
      sendBtn.click();
      await sleep(1000);
      window.__b2.push({n: m.n, p: m.p, s: 'sent'});
    } else {
      window.__b2.push({n: m.n, p: m.p, s: 'no_send_button'});
    }
    
    // 5. 返回上一页
    uni.navigateBack();
    await sleep(2000);
  }
  window.__b2d = true;
}

run();
```

#### 监控批量发送进度

通过定期检查结果变量来监控进度：
```
工具: browser_evaluate
参数:
  script: "return JSON.stringify({done: window.__b2d, results: window.__b2});"
```

## 四、核心技术要点

### 4.1 uni-app框架特殊处理

喜上媒捎使用uni-app框架开发，HTML中使用自定义元素（如`uni-text`、`uni-view`、`uni-textarea`），而非标准HTML元素。

**标准元素选择器不生效的情况：**
```javascript
// ❌ 可能无法找到uni-app元素
document.querySelector('textarea');
document.querySelector('button');

// ✅ 正确的方式：使用uni-app自定义标签
document.querySelector('uni-textarea textarea');  // uni-textarea内部的textarea
document.querySelectorAll('uni-text');            // 文本元素
```

### 4.2 Vue双向绑定兼容

直接修改input/textarea的value不会触发Vue的响应式更新。需要使用原生setter：

```javascript
var nativeSetter = Object.getOwnPropertyDescriptor(
  window.HTMLTextAreaElement.prototype, 'value'
).set;
nativeSetter.call(textarea, '消息内容');
textarea.dispatchEvent(new Event('input', {bubbles: true}));
```

### 4.3 uni-app路由导航

uni-app使用自身的路由API，不能通过修改URL来导航：

```javascript
// ❌ 直接修改URL可能导致页面重新加载
window.location.href = '/#/pages/...';

// ✅ 使用uni-app的导航API
uni.navigateTo({url: '/pages/tabbar/messages/chatroom'});
uni.navigateBack();
uni.switchTab({url: '/pages/tabbar/messages/chatroom'});
```

### 4.4 eventChannel页面通信

uni-app页面间通过eventChannel传递数据：

```javascript
uni.navigateTo({
  url: '/pages/tabbar/messages/chatroom',
  success: function(res) {
    res.eventChannel.emit('acceptDataFromOpenerPage', {
      isOk: true,
      id: memberId,
      phone: phone,
      nickname: nickname
    });
  }
});
```

### 4.5 获取App内部数据

通过`getApp()`函数获取uni-app的全局数据：

```javascript
var app = getApp();
var conn = app.globalData.emConnection;  // 环信IM连接对象
var userInfo = app.globalData.userInfo;   // 用户信息
```

## 五、工具函数参考

### 5.1 browser_snapshot - 页面快照

获取页面的无障碍树结构，返回每个元素的`ref`引用ID。

```
参数:
  compact: boolean       - 紧凑模式（默认false）
  interactive: boolean   - 仅返回可交互元素（默认false）
  selector: string       - CSS选择器，限定快照范围
  maxDepth: number        - 最大深度（默认20）

返回: YAML格式的页面元素树，包含ref引用ID
```

### 5.2 browser_click - 点击元素

```
参数:
  element: string        - 元素描述（必填）
  ref: string            - 元素引用ID（必填，从快照获取）
  button: string         - 鼠标按钮: left/right/middle（默认left）
  doubleClick: boolean   - 是否双击（默认false）
  holdDurationMs: number - 按住时长（毫秒，默认0）
  modifiers: array       - 修饰键: Control/Shift/Alt/Meta
```

### 5.3 browser_type - 输入文本

```
参数:
  element: string        - 元素描述（必填）
  ref: string            - 元素引用ID（必填）
  text: string           - 要输入的文本（必填）
  clear: boolean         - 是否先清空（默认false）
  slowly: boolean        - 是否逐字符输入（默认false）
  submit: boolean        - 输入后是否按回车（默认false）
```

### 5.4 browser_evaluate - 执行JavaScript

```
参数:
  script: string         - 要执行的JavaScript代码（必填）
  
注意: 不能访问document.cookie、localStorage、sessionStorage
```

### 5.5 browser_wait_for - 等待

```
参数:
  text: string          - 等待文本出现
  textGone: string      - 等待文本消失
  time: number           - 等待时间（秒，最大60）
  timeout: number        - 最大超时（毫秒，默认30000）
```

### 5.6 browser_navigate - 导航

```
参数:
  url: string            - 目标URL（必填）
  newTab: boolean        - 是否在新标签页打开（默认false）
  position: string       - 标签页位置: active/side
```

### 5.7 browser_take_screenshot - 截图

```
参数:
  filename: string      - 保存文件名
  fullPage: boolean      - 是否截取完整页面（默认false，仅可视区域）
  ref: string            - 指定元素CSS选择器截图
```

## 六、常见问题与解决方案

### 6.1 找不到元素

**问题：** `browser_snapshot` 返回的元素ref后续操作时报找不到。

**原因：** 页面发生了变化（如弹窗出现、动画完成），之前的ref已失效。

**解决：** 每次操作前重新获取快照，使用最新的ref。

### 6.2 uni-app自定义元素无法操作

**问题：** 标准CSS选择器无法定位uni-app元素。

**解决：** 使用`uni-`前缀的自定义标签名查询：
```javascript
document.querySelectorAll('uni-text');
document.querySelector('uni-textarea textarea');
```

### 6.3 Vue双向绑定不生效

**问题：** 直接设置input.value后Vue未更新。

**解决：** 使用原生setter + dispatchEvent：
```javascript
var setter = Object.getOwnPropertyDescriptor(
  window.HTMLInputElement.prototype, 'value'
).set;
setter.call(input, value);
input.dispatchEvent(new Event('input', {bubbles: true}));
```

### 6.4 页面加载等待

**问题：** 操作太快，页面还没加载完。

**解决：** 使用增量等待策略：
```
等待2秒 → 获取快照 → 检查是否就绪 → 否则再等2秒 → 再检查
```

### 6.5 弹窗处理

**问题：** 原生弹窗（alert/confirm/prompt）阻塞操作。

**解决：** 默认confirm()返回true，prompt()返回默认值。也可以在触发前预设：
```
工具: browser_handle_dialog
参数:
  accept: false       # confirm点取消
  promptText: "value" # prompt输入值
```

## 七、操作流程总结

### 本次喜上媒捎项目的完整操作流程

```
1. browser_navigate → 打开 https://h-app.xsms-club.com/
2. browser_snapshot  → 获取登录页面元素
3. browser_type      → 输入手机号
4. browser_type      → 输入密码
5. browser_evaluate  → 勾选用户协议（uni-app特殊处理）
6. browser_click     → 点击登录
7. browser_wait_for  → 等待登录成功
8. browser_evaluate  → 跳过引导页
9. browser_evaluate  → 导航到会员个人主页
10. browser_evaluate → 打开聊天页面（通过eventChannel传递会员信息）
11. browser_snapshot → 获取聊天页面元素
12. browser_type     → 输入情话消息
13. browser_click    → 点击发送按钮
14. browser_snapshot → 验证消息已发送
15. browser_evaluate → 返回并重复10-14发送给下一个会员
16. browser_click    → 导航到消息列表页面
17. browser_snapshot → 验证所有消息记录
18. browser_take_screenshot → 截图保存证据
```

## 八、安全注意事项

1. **凭据安全：** App密码和环信IM密码不应硬编码在脚本中
2. **令牌存储：** GitHub令牌等敏感信息应使用`.git-credentials`文件存储并设置`chmod 600`权限
3. **用户隐私：** 会员手机号等个人信息在文档中应做脱敏处理
4. **操作审计：** 所有自动化操作应有日志记录，便于追溯
5. **合规使用：** 自动化操作应遵守App的用户协议和相关法律法规
