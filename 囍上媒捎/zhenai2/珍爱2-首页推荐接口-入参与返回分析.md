# 珍爱2 首页推荐接口 · 入参与返回分析文档

> **说明**：本文档基于对珍爱网公开 H5 页面 JS（`home.js`、`zhenai-2.0.2.min.js`）的**静态逆向分析**整理，用于复刻项目的 API 对接参考，**不含对线上服务的实际调用**。
>
> 由于原版 App 的 `com.zhenai.*` 业务代码被加固保护（`libdexvmp.so`/`libzxprotect.so`），App 端推荐接口无法从 APK 静态还原，本文以 H5 端同源接口契约为准，字段结构对 App 端同样适用（App 端主机为 `api.zhenai.com`）。

---

## 一、接口概述

| 项 | 值 |
|---|---|
| 接口路径 | `/recommend/listQualityMember.do` |
| 请求方式 | **GET** |
| H5 完整 URL | `//www.zhenai.com/api/recommend/listQualityMember.do` |
| App 完整 URL | `https://api.zhenai.com/recommend/listQualityMember.do` |
| 用途 | 首页"优质会员推荐"列表（登录后拉取） |
| 登录要求 | **必须已登录**（未登录返回 `-00004`） |
| 数据来源 | H5 首页 JS `home.js` 中 `rr` 函数（`var rr = function() { return le("/recommend/listQualityMember.do") }`） |

## 二、调用链路（H5 首页）

```
珍爱网首页 JS
    └── rr()                      # 推荐接口调用入口
          └── le(url, data)       # GET 请求封装
                └── fe({ url, data, type:"get" })
                      ├── URL 前缀: //www.zhenai.com/api
                      ├── 注入公共参数: data=设备指纹(screenPrint)
                      └── 走 Z.ajax() 发送(自动携带 UA / sid cookie / 时间戳 _)
```

对应复刻项目中的链路：

```
RecommendFragment (首页)
    └── NetworkClient.apiService.getRecommendList(...)   # 待新增
          └── RequestInterceptor                           # 注入 ua / _ / data
                └── Retrofit GET 请求 → api.zhenai.com
```

## 三、入参（Request）

### 3.1 业务参数

`listQualityMember.do` 在 H5 首页 JS 中调用时**未传任何业务参数**（`rr` 调用 `le("/recommend/listQualityMember.do")` 无第二参数）。

> 说明：分页、筛选等参数由**各端自己的推荐策略**决定，H5 首页默认只拉第一页。App 端首页在加固代码内，可能额外携带分页参数（如 `page`/`pageSize`）——字段名无法静态确认，对接时以实际抓包为准。

### 3.2 公共参数（每次请求由拦截器注入）

以下参数由请求封装层自动追加，调用方**无需手动传**：

| 参数名 | 位置 | 来源 | 说明 |
|---|---|---|---|
| `ua` | query | `Z.getUA()` 生成 | 设备 UA 标识（复刻项目已在 RequestInterceptor 注入） |
| `_` | query | `System.currentTimeMillis()` | 时间戳，防缓存 |
| `data` | query | `ie()` 异步获取 `screenPrint` | 设备指纹（WAF 风控用，见下节） |
| `sid` | cookie | `Z.cookie.get("sid")` | 登录会话标识（登录成功后下发） |
| `token` | cookie | 登录返回 | 登录令牌（原 App 的 `_pc_login_*` 系列 cookie 之一） |

### 3.3 设备指纹 `data`（screenPrint）生成

```javascript
// 来自 home.js 的 ie() 函数
var e = sessionStorage.getItem("screenPrint");
// 若缓存没有, 则调用指纹服务生成:
window._fmOpt = {
    partner: "zhenai",
    appName: "pcPrint",
    token: "zhenai" + "-" + (new Date().getTime()) + "-" + Math.random().toString(16).substr(2),
    fpHost: "https://secdfinger.zhenai.com",
    fmb: true,
    cub: true,
    ...
}
```

关键点：
- 指纹服务主机：`secdfinger.zhenai.com`（项目 Constants 中 `FINGER_HOST` 已记录）
- 指纹值会持久化到 `sessionStorage.screenPrint`，一次生成多次复用
- 复刻项目当前用 `RequestInterceptor { null }` 占位（指纹不注入），会导致接口可能被 WAF 拦截

## 四、返回（Response）

### 4.1 统一外层结构

所有珍爱接口统一返回（项目 `ApiResponse` 已定义）：

```json
{
  "isError": false,            // Boolean 是否错误
  "errorCode": "",             // String 错误码, 为空表示成功
  "errorMessage": "",          // String 错误信息
  "data": { ... }              // Object 业务数据, 见下
}
```

### 4.2 错误码（推荐接口相关）

| errorCode | 含义 | 处理 |
|---|---|---|
| 空串 / null | 成功 | 渲染 data |
| `-00004` | 未登录 / 登录态失效 | **跳转登录页**（H5 代码：`window.location.href="https://www.zhenai.com/n/login?...`） |
| 其他 | 见 login.js 错误分支 | 按 errorMessage 提示 |

### 4.3 推荐列表 data 结构（推断）

依据原 APK 中 `recommend_profile7_*` 系列资源与 H5 推荐卡片的字段使用，`data` 预计结构如下（**字段名以实际返回为准**）：

```json
{
  "data": {
    "total": 200,                       // 推荐总数(推断)
    "memberList": [                     // 推荐会员列表(推断字段名)
      {
        "memberID": 12345678,           // 会员ID(已确认存在)
        "nickname": "小芳",             // 昵称
        "avatar": "https://.../a.jpg",  // 头像
        "age": 28,                      // 年龄(已确认使用)
        "height": 165,                  // 身高(cm)
        "city": "佛山",                 // 城市
        "industry": "互联网",           // 职业(推断)
        "education": "本科",            // 学历(推断)
        "monthIncome": 20000,           // 月收入(推断)
        "signature": "...",             // 个性签名
        "photoList": [...],             // 相册照片
        "marryStatus": 0,               // 婚况(推断)
        "isVip": false,                 // 是否会员(推断)
        "verifyStatus": {...}           // 认证状态(实名/学历/收入)
      }
    ]
  }
}
```

> **重要**：`memberList` 等列表字段名为推断。因 App 端被加固、H5 首页仅消费不深挖结构，**确认方法**：
> 1. 复刻项目接入后用 `ApiLogInterceptor` 抓一次真实返回（需登录态）
> 2. 或参考珍爱网公开接口文档 / 其他逆向项目
> 接入时建议先用 `ApiResponse<JsonObject>` 泛型接收，打印原始 JSON 后再固化为 data class。

## 六、注意事项

1. **登录前置**：推荐接口必须携带有效 `sid`/`token` cookie，未登录一律返回 `-00004`。
2. **设备指纹**：H5 端通过 `secdfinger.zhenai.com` 生成 `screenPrint` 作为 `data` 参数；复刻项目当前未实现指纹，可能触发 WAF 拦截（`428` 响应）。
3. **加固限制**：App 端推荐接口真实入参（分页/筛选）在原 APK 加固代码内，无法静态还原；如需精确字段，必须通过合法渠道获取接口文档或自行抓包确认。
4. **非真实数据**：本文档为静态逆向分析结果，不含任何线上真实会员数据。
